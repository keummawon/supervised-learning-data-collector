# 지도학습 데이터 수집기 (Supervised Learning Data Collector)

인공지능 지도학습에 쓸 데이터를 클래스별로 모으는 웹 페이지입니다.
첫 화면에서 수집할 데이터 종류(이미지 · 음성 · 텍스트)를 고르면 해당 수집기로 들어갑니다.

👉 바로 사용하기: https://keummawon.github.io/image-data-collector/

| 종류 | 상태 | 파일 |
|---|---|---|
| 🖼 이미지 | 사용 가능 | `image.html` |
| 🎤 음성 | 🔒 잠김 | – |
| 📝 텍스트 | 🔒 잠김 | – |

## 🖼 이미지 수집기
- 범주/클래스 이름을 입력하고 웹캠으로 사진 찍기
  - 버튼을 한 번 누르면 1장, 길게 누르면 연속 촬영
- 이미지 크기 선택 (224 / 400 / 640px 정사각형), 좌우 반전
- 찍은 사진 목록 확인, 크게 보기, 삭제 (키보드 ← → 이동, Delete 삭제)
- ↺ 리셋으로 처음부터 다시 시작
- 왼쪽 위 **← 홈**을 누르면 첫 화면으로 돌아감

### 💾 저장 방식
- **크롬·엣지(PC)**: 오른쪽 위의 📁 저장 폴더 연결 버튼으로 폴더를 한 번 고르면, 그 안에 클래스 이름 폴더가 만들어져 `1.jpg, 2.jpg …`로 저장됩니다.
  - 예: `바탕화면 > 사과 > 1.jpg, 2.jpg …`
  - **같은 이름 폴더가 이미 있으면** 새로 만들지 않고, 저장 전에 한 번 물어본 뒤 그 폴더에 **이어서** 저장합니다.
    - 예: `사과` 폴더에 1~20번이 있으면 → "21번~40번으로 이어서 저장할까요?"
    - 연결한 폴더 이름이 클래스 이름과 같으면 그 폴더에 바로 저장 (`우리반 > 우리반`처럼 겹치지 않음)
    - 취소하면 아무것도 저장하지 않음
  - 다른 위치로 바꾸려면 오른쪽 위의 **변경** 클릭
- **그 외 브라우저**: `클래스이름.zip` 파일로 다운로드

### 시작 번호
**시작 번호**를 정할 수 있습니다. 예: 21을 넣으면 `21.jpg, 22.jpg …`
- 썸네일에 붙는 번호가 저장될 파일 번호입니다.
- 시작 번호가 폴더에 이미 있는 번호보다 작으면, 덮어쓰지 않도록 마지막 번호 다음부터 자동으로 이어서 저장합니다.
- 리셋하면 1로 돌아갑니다.

## 실행 방법
위의 사이트 주소로 접속하거나, `index.html`을 크롬에서 열면 됩니다. 설치할 것은 없습니다.
사진과 데이터는 내 컴퓨터에만 저장되고 인터넷으로 전송되지 않습니다.
