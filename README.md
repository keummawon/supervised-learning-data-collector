# 지도학습 데이터 수집기 (Supervised Learning Data Collector)

인공지능 지도학습에 쓸 데이터를 클래스별로 모으는 웹 페이지입니다.
첫 화면에서 수집할 데이터 종류(이미지 · 음성 · 텍스트)를 고르면 해당 수집기로 들어갑니다.

👉 바로 사용하기: https://keummawon.github.io/supervised-learning-data-collector/

| 종류 | 파일 | 상태 |
|---|---|---|
| 🖼 이미지 | `image.html` | 사용 가능 |
| 🎤 음성 | `voice.html` | 사용 가능 |
| 📝 텍스트 | (아직 없음) | 준비 중 |

## 🖼 이미지 수집기
클래스/범주마다 한 줄씩 **사진 찍기 · 찍은 사진 · 사진 확인**이 나란히 있습니다.
- 맨 아래 **＋ 클래스/범주 추가**를 누르면 다음 줄(두 번째, 세 번째 …)이 생김
- 줄마다 이름 입력, **✕ 삭제**로 그 줄 지우기
- **사진 찍기**: 카메라 켜기 → 사진 찍기 (한 번 누르면 1장, 길게 누르면 연속 촬영). 웹캠 하나를 모든 줄이 같이 씀
- **찍은 사진**: 그 클래스/범주에서 찍은 사진만 모여 보임
- **사진 확인**: 사진을 누르면 크게 보기, ◀ ▶ 이동, 삭제 (키보드 ← → / Delete)
- 위쪽 설정 줄: 사진 크기 (224 / 400 / 640px 정사각형), 좌우 반전 — 모든 줄에 같이 적용
- ↺ 리셋으로 처음(클래스/범주 1개)부터 다시 시작
- 왼쪽 위 **← 홈**을 누르면 첫 화면으로 돌아감

### ⚠️ 다운로드 전 경고창
**⬇ 다운로드**를 누르면 먼저 "각 클래스/범주의 **특징·패턴을 잘 나타내는 사진**인지 확인하세요" 경고창이 뜹니다.
- 흐리거나, 대상이 잘 안 보이거나, 다른 클래스/범주와 헷갈리는 사진은 삭제하도록 안내하고 저장할 사진 수를 보여 줍니다.
- **확인했어요, 다운로드** → 저장 / **다시 확인할게요** (또는 Esc) → 저장하지 않고 돌아감

### 💾 다운로드 (저장 방식)
**⬇ 다운로드**를 누르면 사진이 있는 **모든 클래스/범주가 한꺼번에 각각 이름 폴더로** 저장됩니다.
- 예: `바탕화면 > 사과 > 1.jpg, 2.jpg …`, `바탕화면 > 바나나 > 1.jpg …`
- 사진이 있는 클래스/범주는 이름이 있어야 하고, 이름이 서로 겹치면 안 됩니다.

- **크롬·엣지(PC)**: 오른쪽 위의 📁 저장 폴더 연결 버튼으로 폴더를 한 번 고르면, 그 안에 클래스/범주 이름 폴더가 만들어집니다.
  - **같은 이름 폴더가 이미 있으면** 새로 만들지 않고 그 폴더에 **이어서** 저장합니다. 저장 전에 어떤 폴더에 몇 번부터 저장되는지 한 번 물어봅니다.
    - 예: `사과` 폴더에 1~20번이 있으면 → 21번부터
    - 연결한 폴더 이름이 클래스/범주 이름과 같으면 그 폴더에 바로 저장 (`우리반 > 우리반`처럼 겹치지 않음)
    - 취소하면 아무것도 저장하지 않음
  - 다른 위치로 바꾸려면 오른쪽 위의 **변경** 클릭
- **그 외 브라우저**: ZIP 파일 하나로 다운로드 (안에 클래스/범주별 폴더)

### 파일 번호
- 새 폴더는 `1.jpg`부터 저장됩니다.
- 폴더에 이미 사진이 있으면 덮어쓰지 않도록 마지막 번호 다음부터 자동으로 이어서 저장합니다.

## 🎤 음성 수집기
이미지 수집기와 같은 구조로, 클래스/범주마다 한 줄씩 **녹음하기 · 녹음한 소리 · 소리 확인**이 나란히 있습니다.
- **녹음 길이**: 위쪽에서 **1초 / 2초 / 3초 / 5초** 중 선택 (기본 5초)
  - 짧은 단어·효과음은 1~2초, 생활·환경 소리는 3~5초 권장
  - 이미 녹음한 소리와 길이가 달라지면 한 번 물어봄 (한 프로젝트 안에서는 길이를 맞추는 게 좋음)
  - 저장되는 파일은 고른 길이에 정확히 맞춤 (짧으면 뒤를 무음으로 채움)
- **녹음하기**: 마이크 켜기 → 🎙 녹음 버튼을 누르면 고른 시간 동안 녹음 (0초부터 채워지는 파형, 초 눈금, 남은 시간 표시)
- **녹음한 소리**: 그 클래스/범주의 녹음이 파형 모양으로 모여 보임
- **소리 확인**: 녹음을 누르면 초 눈금이 있는 큰 파형과 재생 버튼, ◀ ▶ 이동, 삭제 (키보드 ← → / Delete)
- ＋ 클래스/범주 추가, ✕ 삭제, ↺ 리셋은 이미지 수집기와 같음
- **⬇ 다운로드**: 경고창("특징·패턴을 잘 나타내는 소리인지 확인") 뒤에 모든 클래스/범주를 한꺼번에 이름 폴더로 저장
  - 파일 형식: `1.wav, 2.wav …` (모노, 16bit)
  - 같은 이름 폴더가 있으면 마지막 번호 다음부터 이어서 저장
  - 저장 폴더는 이미지와 따로 기억 (처음 한 번 연결)

## 실행 방법
위의 사이트 주소로 접속하거나, `index.html`을 크롬에서 열면 됩니다. 설치할 것은 없습니다.
사진과 데이터는 내 컴퓨터에만 저장되고 인터넷으로 전송되지 않습니다.
